## 四、详细问题记录

### 问题 01：Continue 进入游戏后不一定回到最后保存位置

- **所属模块**：主菜单 / 存档系统 / 玩家恢复
- **相关脚本**：
  - `SaveManager`
  - `SaveData`
  - `PlayerSaveLoader`
  - `SceneLoader`
  - `MainMenuGameEntry`
- **问题描述**：  
  从主菜单点击 Continue 后，可以进入游戏场景，但玩家位置不一定恢复到最后保存的位置。
- **出现条件**：  
  使用已有存档进行 Continue 或读档进入游戏时出现。
- **当前状态**：排查中
- **可能原因**：
  - 存档数据中未正确保存玩家位置
  - 场景进入后没有正确应用位置数据
  - `PlayerSaveLoader` 挂载或执行时机不正确
  - Continue 流程只是进入场景，没有完整执行读档恢复
- **已尝试处理**：
  - 检查过 `PlayerSaveLoader` 是否挂载到 Player
  - 检查过 Continue 功能能否正常进入场景
- **后续计划**：
  - 重点检查 `SaveManager` 保存的数据内容
  - 检查 `PlayerSaveLoader` 的调用时机
  - 检查 Continue 与 New Game 是否错误复用同一套进入逻辑

---

### 问题 02：玩家读档后的状态恢复仍需继续验证

- **所属模块**：存档系统 / 玩家系统
- **相关脚本**：
  - `SaveData`
  - `SaveManager`
  - `PlayerSaveLoader`
- **问题描述**：  
  当前已经具备基础读档能力，但玩家在读档后的状态恢复是否完整，仍需进一步测试。
- **出现条件**：  
  读取不同存档或在不同阶段存档后进行恢复时。
- **当前状态**：排查中
- **可能原因**：
  - 当前恢复逻辑只覆盖了位置，没有覆盖其他运行状态
  - 场景切换后恢复逻辑触发顺序不稳定
- **已尝试处理**：
  - 已完成基础存档与场景进入流程联调
- **后续计划**：
  - 明确 `SaveData` 当前保存了哪些字段
  - 明确读档后哪些内容应恢复、哪些内容由场景初始化提供
  - 逐项测试玩家位置、任务状态、交互状态是否恢复正确

---

### 问题 03：暂停菜单、设置菜单、音频设置之间的联动需要继续稳定

- **所属模块**：暂停系统 / UI 系统 / 音频系统
- **相关脚本**：
  - `PauseManagerrScript`
  - `PauseMenuController`
  - `AudioManager`
  - `AudioController`
  - `AudioSettingsBinder`
- **问题描述**：  
  暂停菜单、设置面板和音频设置之间已有基础联动，但整体逻辑仍需进一步稳定和统一。
- **出现条件**：  
  打开暂停菜单、进入设置、调整音量、返回主暂停界面时。
- **当前状态**：排查中
- **可能原因**：
  - 暂停状态控制与 UI 面板控制职责存在交叉
  - 音频设置逻辑分散在多个脚本中
  - `Time.timeScale`、面板显示状态与音频状态之间同步还不够稳定
- **已尝试处理**：
  - 已完成基础暂停菜单
  - 已完成部分音量控制逻辑
  - 已处理过部分设置菜单显示问题
- **后续计划**：
  - 明确 `PauseManagerrScript` 只负责暂停状态
  - 明确 `PauseMenuController` 只负责 UI 切换
  - 明确 `AudioManager` 与设置界面的职责边界

---

### 问题 04：Unity Inspector 挂载、Button OnClick、对象引用容易丢失

- **所属模块**：全局
- **相关范围**：
  - 场景对象
  - UI 对象
  - 预制体
  - Button 事件
  - `public` / `[SerializeField]` 字段
- **问题描述**：  
  当前项目很多功能的正确运行依赖 Unity Inspector 中的挂载关系和对象引用，修改脚本后容易出现功能失效。
- **出现条件**：  
  修改脚本字段、调整对象层级、更换脚本、复制预制体、切换场景后。
- **当前状态**：长期注意
- **可能原因**：
  - Unity 编辑器逻辑天然依赖 Inspector 绑定
  - 改名、删字段、换脚本后容易导致引用失效
- **已尝试处理**：
  - 已在开发过程中多次通过手动检查挂载解决问题
- **后续计划**：
  - 每次改脚本后优先检查 Inspector
  - 重要 UI 按钮记录其 OnClick 绑定对象与方法
  - 后续逐步整理“脚本—对象挂载关系表”
